# Lockave for Windows — downloads

Installers for the Lockave Windows app. **Binaries only — there is no source
code in this repository.**

## Download

**[Download the latest version](https://github.com/pranav12432/lockave-downloads/releases/latest/download/Lockave-Setup.msi)**

Or pick a specific version from [Releases](https://github.com/pranav12432/lockave-downloads/releases).

## Requirements

- 64-bit Windows 10 or Windows 11
- Administrator rights to install (the app installs a Windows service)

## Before you install

**The installer is not yet code-signed.** Windows will show *"Windows protected
your PC"* from SmartScreen, and some antivirus software may flag it. If you
downloaded it from the link above or from lockave.com, it is the file we
published — choose **More info → Run anyway**. Code signing is in progress.

We would rather say this plainly than have you wonder whether the warning is
real.

## What it does

Lockave for Windows blocks adult content for **everyone who uses the computer**,
in every browser, and reports to your Lockave dashboard so you can see that
protection is working. It also enforces the daily app time limits you set at
[lockave.com](https://lockave.com).

It is **not** per-person on a shared PC: a Windows service filters the whole
machine and cannot tell which family member is at the keyboard. Per-child time
limits and schedules stay with the Lockave browser extension.

## Setting it up

1. Install, then open **Lockave** from the Start menu.
2. Sign in to your Lockave account in the window that opens.
3. Choose **Link this PC**.

Blocking starts working immediately after installation, whether or not the PC is
linked. Linking is what adds it to your dashboard and lets you be told if its
protection stops working.

## Removing it

Settings → Apps → Installed apps → **Lockave for Windows** → Uninstall.
Uninstalling restores your browsers' original settings and your computer's
original network configuration.
